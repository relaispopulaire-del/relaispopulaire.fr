Gestion des galeries

Espace réservé à Relais Populaire Média. Il sert à créer des galeries client, à y ajouter des photos et à en supprimer.

Se connecter

Créer sa clé d’accès (une seule fois)

  1. Connecté à GitHub, ouvrez github.com/settings/personal-access-tokens/new.
  2. Token name : Galeries RPM. Expiration : la durée de votre choix (par exemple 1 an).
  3. Repository access : « Only select repositories » → relaispopulaire.fr.
  4. Permissions → Repository permissions → Contents : « Read and write ».
  5. Cliquez sur Generate token, copiez la clé (elle commence par github_pat_) et collez-la ci-dessus.

La clé reste dans votre navigateur et n’est envoyée qu’à GitHub. Ne la partagez avec personne : elle donne accès au contenu du site.
